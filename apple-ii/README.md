# Apple II

An Apple II-inspired Omarchy theme with a near-black green screen and bright
green phosphor text.

The theme uses opaque, square-cornered surfaces and subtle scanline-like
styling in supported CSS surfaces. It is designed for the Omarchy Quattro
release and uses Adwaita Mono by default.

For a more authentic bitmap appearance, install an IBM VGA or Apple II-style
bitmap font and set it as the terminal and shell font in your local
configuration.

## Palette

- Screen: near-black green
- Phosphor: green
- Contrast: dim, standard, and bright phosphor shades
