# Japan Temple

A quiet Omarchy theme inspired by a Japanese wooden house beside a mossy
waterfall: cedar-brown shadows, blue-green mist, stone gray, and soft lantern
warmth.

## Palette

- **Misty teal:** `#86b8b0`
- **Deep cedar slate:** `#182328`
- **Moss:** `#8eaa86`
- **Water:** `#83b9b6`
- **Lantern wood:** `#c49a78`
- **Fog:** `#d6e2df`

## Included configuration

The theme follows the broader `purrism` structure and includes:

- Colors and Hyprland appearance
- Alacritty, Foot, Ghostty, and Kitty terminal settings
- Omarchy bar, controls, launcher, lock, menu, notifications, popups, and tooltips
- Hyprlock, Mako, SwayOSD, Walker, and btop styling
- Chromium/icon metadata, Starship prompt, Neovim, and VSCodium metadata

## Backgrounds

The theme includes two wallpaper options in `backgrounds/`:

- `1-darker-tree-view.jpg` for a subdued, dark wooden atmosphere
- `2-sun-water-view.jpg` for a brighter garden-and-water atmosphere

Both are intended to keep the wallpaper behind the misty teal interface.

## Additional background suggestion

The theme intentionally does not bundle artwork. For the intended atmosphere,
choose a wallpaper showing a Japanese garden or wooden interior with a small
waterfall, bonsai, moss, and soft overcast light, then place it in this theme's
`backgrounds/` directory or add it through Omarchy's background picker.

## Installation

Copy this directory into `~/.config/omarchy/themes/japan-temple`, then apply it
with:

```bash
omarchy theme set japan-temple
```
