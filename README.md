# Omarchy Themes

A collection of themes for [Omarchy](https://github.com/basecamp/omarchy) with different colors, aesthetics, and visual styles.

> [!WARNING]
> **Omarchy Quattro Compatibility**
>
> Not all themes in this repository have been migrated to **Omarchy Quattro** yet. Some themes may still use older configurations and might require adjustments before they work correctly.
>
> Check the individual theme documentation and compatibility status before installing.

## Repository Structure

Each theme is organized in its own directory.
The actual directory structure may vary as the collection grows.
